# 🎯 Valorant Aim Trainer

Бесплатный 3D-тренажер для стрельбы, адаптированный под сенсу и FOV в Valorant.

## 🚀 Как скачать и играть (Для игроков)
Вам не нужно ничего компилировать!
1. Перейдите в раздел **[Releases](../../releases/latest)** (справа на этой странице).
2. Скачайте последний ZIP-архив (например, `AimTrainer_v1.0.zip`).
3. Распакуйте архив в любую папку.
4. Запустите `AimTrainer.exe` и играйте!

*Примечание: игра всегда запускается в полноэкранном режиме. Сенса и настройки сохраняются в файле `settings.cfg` рядом с `.exe`.*

## 🛠️ Для разработчиков (Сборка из исходников)
Если вы хотите изменить код:
1. Установите Visual Studio Build Tools (C++) и CMake.
2. Скачайте `raylib` (MSVC 16) и положите по пути `C:/AimTrainer/raylib-5.5_win64_msvc16`.
3. Соберите проект через CMake в VS Code.
